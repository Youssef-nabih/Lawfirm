# تحديث واجهة مكتب المحاماة ومهام الشركات

## التشغيل
افتح index.html كالمعتاد. ملفات theme.css وworkspace.js يجب نشرها بجوار index.html وapp.js.

## تفعيل مهام الشركات
1. افتح مشروع Supabase المستخدم بالفعل في app.js.
2. من SQL Editor شغّل محتوى migrations/001_company_tasks.sql مرة واحدة.
3. افتح النظام بحساب معتمد، ثم إدارة الشركات ← ملف الشركة والمهام.

الملف ينشئ جدول company_tasks مستقلًا، مربوطًا بجدول companies، مع سياسات صلاحيات على مستوى الصفوف. يجب أن يكون جدول profiles الحالي متاحًا للمستخدم لقراءة ملفه، وجدول companies محميًا بسياسات الوصول المناسبة للمكتب؛ سياسات المهام تحترم الشركات المتاحة لذلك المستخدم.

المدير والموظف المعتمدان يستطيعان إدارة مهام الشركات التي يمكنهما رؤيتها. المستخدم المعتمد الآخر يعرض المهام فقط. حذف الشركة يحذف مهامها التابعة تلقائيًا. المهام العامة وإحصاءاتها تظل منفصلة.

بعد إضافة شركة جديدة يفتح ملفها مباشرة لإضافة مهامها. المهام تتضمن عنوانًا وتفاصيل وموعدًا وحالة إكمال. لا يتم حفظ أي بيانات مهام في التخزين المحلي.

## التحقق
تم اختبار CRUD وعزل الشركات وإعادة التحميل وعرض النصوص بأمان وحالة الجدول غير المفعّل والموبايل باستخدام قاعدة بيانات محاكاة في tests/workspace.cjs. لم يتم تشغيل ترحيل SQL على قاعدة حية أو اختبار صلاحيات RLS فعليًا؛ يلزم التحقق بحساب مدير وموظف وحساب غير معتمد بعد التفعيل.

لتشغيل اختبار الواجهة: node tests/workspace.cjs (يتطلب Playwright وMicrosoft Edge).

## النسخ الاحتياطي والاستعادة

بعد تفعيل مهام الشركات، شغّل `migrations/002_office_backups.sql` مرة واحدة في SQL Editor لنفس مشروع Supabase. ثم حدّث الموقع وسجّل الدخول بحساب مدير معتمد، وافتح «النسخ الاحتياطي» من القائمة الجانبية. يجب نشر `backup.js` مع بقية ملفات الموقع.

- نسخة البيانات تشمل الجداول السبعة: الشركات والموكلين والقضايا والجلسات والمصروفات والمهام العامة ومهام الشركات.
- النسخة بالمرفقات تشمل الملفات المرتبطة بحقول `_url` في هذه السجلات داخل bucket `documents`. لا تشمل الملفات اليتيمة أو الروابط الخارجية أو حسابات المصادقة أو ملفات الموظفين أو طلبات الانضمام أو إعدادات قاعدة البيانات والسياسات. هذه نسخة لبيانات عمل المكتب وليست نسخة بنية تحتية كاملة للمشروع.
- النسخة ملف JSON غير مشفّر، يحتوي تحقق SHA-256 لكشف التلف، وليس توقيعًا لإثبات مصدر الملف. احفظه بعيدًا عن مشاركة الملفات العامة.
- الأداة محدودة بـ100 MiB للملف النهائي لحماية ذاكرة المتصفح، وترميز المرفقات يزيد الحجم. الأرشيفات الأكبر تحتاج حل نسخ على الخادم. ليست هذه الميزة بديلًا عن النسخ الآلي المستقل للقاعدة والتخزين.
- الاستعادة لنفس المشروع وبنية الجداول، تضيف السجلات المفقودة وتستبدل المتطابقة وتحافظ على السجلات الأخرى. تحتاج الحسابات المشار إليها في البيانات إلى أن تظل موجودة. تغيير المشروع أو البنية يحتاج ترحيلًا بواسطة المسؤول.
- دوال التصدير والاستعادة تتحقق من دور المدير وحالة اعتماده وتعمل بصلاحيات المتصل وبسياسات RLS القائمة. يجب أن تسمح سياسات المكتب للمدير بقراءة كل سجلات المكتب وتعديلها. المساعد الوحيد الذي يعمل بصلاحيات المالك يضبط عدادات المعرفات للجداول المحددة بعد تحقق المدير.
- يتم رفع المرفقات المستعادة بأسماء جديدة، ثم تغيير روابط السجلات داخل معاملة واحدة. لا تُحذف المرفقات القديمة. إذا فشل رفع الملفات قبل محاولة حفظ البيانات تحاول الأداة تنظيف الملفات الجديدة؛ وإذا كانت نتيجة الحفظ غير مؤكدة بسبب الاتصال تحتفظ بها وتطلب التحقق قبل إعادة المحاولة.
- عند تغيير أي بيانات بعد المعاينة ترفض الاستعادة ويجب إعادة اختيار الملف للمعاينة مرة أخرى. نفّذ النسخ والاستعادة في وقت هادئ؛ العملية تستخدم أقفال جداول مؤقتة لضمان اتساق البيانات.

### تصدير Excel

زر «تصدير Excel» في قسم النسخ الاحتياطي ينشئ ملف XLSX بسبع أوراق عربية، مع اتجاه من اليمين لليسار وفلاتر وتثبيت للعناوين وأعمدة التعريف وصفوف متبادلة الألوان. تظهر أسماء الشركات والقضايا والموكلين بجانب سجلاتها المرتبطة. المبالغ أرقام، والتواريخ قابلة للفرز؛ المواعيد ذات المنطقة الزمنية تعرض بتوقيت القاهرة. أرقام الهواتف والتسجيل نصوص للمحافظة على الأصفار. تُصدّر الحقول الإضافية أيضًا.

المرفقات روابط وليست ملفات مضمّنة. الاستعادة تظل من JSON. يستخدم Excel دالة office_backup_export الموجودة في ملف التفعيل 002، ولا يحتاج SQL جديدًا بعد تشغيلها. يجب نشر excel-export.js ومجلد vendor مع الموقع؛ المكتبة محلية وتُحمّل عند الطلب فقط.

اختبار المتصفح يفحص XLSX بعد تنزيله وفتحه ثانية: الأوراق والأنواع والروابط والأصفار والحقول الإضافية والتثبيت والفلاتر ومنع تحويل نصوص المستخدم إلى صيغ والتصدير الفارغ. تمت مراجعة صور أوراق عينة اصطناعية بأداة Artifact Tool؛ عارضها لا يحاكي اتجاه العربية والأرقام النصية بدقة، لذلك تم فحص القيم والخصائص مباشرة في XLSX. لم يتوفر Microsoft Excel محليًا لاختبار العرض الأصلي.

### اختبارات النسخ
`node tests/backup.cjs` يختبر واجهة المتصفح بقاعدة وتخزين محاكيين: النسخة بالمرفقات، SHA-256، الموافقة، ملفات تالفة أو من مشروع آخر، تغيّر البيانات، أخطاء التنزيل، صلاحية المدير والموبايل.

`node tests/backup-sql.cjs` يختبر ملفات SQL على PostgreSQL محلي عبر PGlite: التصدير، الاستعادة، التراجع عند فشل جدول، الحفاظ على السجلات الأخرى، عدادات المعرفات ومنع غير المدير. حزمة الاختبار مثبتة في مجلد النظام المؤقت `lawfirm-backup-sql-test`، ولا تُستخدم في الموقع. لم يتم تطبيق التهيئة أو اختبار الصلاحيات الفعلية على مشروع Supabase الحي.
